# Дорожная карта 0.4 → 1.0 (утверждена пользователем 2026-10-07)

## Context
Мод на версии 0.3.0 «Бездна». Волна 0.4 начата: измерение `frozen_halls`, портал, Холод, мех, Морозная сталь,
вмёрзшие ангелы и Морозный дух уже есть. Нет загадок Чертогов, Ледяного стража и волка, построек, босса, Акта III,
горячей еды и звука. Параллельно висят этапы C/D из `docs/PUZZLES.md`, открытые баги из `docs/BUGS.md`
(034, 037, 038, 039, 040, 052/053, 057, 059, 060, 062, остатки 005/035) и «Планка качества» из HANDOFF (её почти не трогали).
Состояние сейчас: `./gradlew build` проходит, `lint_assets.py` даёт 0 находок, дерево чистое.
Цель — мод «максимального уровня». Каждую новую механику делаем сразу с защитой от обходов, своими моделями,
светящимися слоями и своим артом. Старое подтягиваем до той же планки.

## Как работаю на каждом шаге (обязательный цикл)
1. Код и ресурсы. Ресурсы только через `tools/gen_*.py` (новый `tools/gen_frozen_puzzles.py`, `gen_frozen_mobs.py`, `gen_archon.py`;
   переводы через `gen_story.lang_patch`), затем `tools/build_assets.sh`.
2. `./gradlew build` → `python3 tools/qa/lint_assets.py` (0 находок) → `tools/devserver.sh` (нет ошибок регистров и датапака).
3. Автопилот: сценарий шага `tools/scenarios/<имя>.txt`. В сценариях загадок две части: «Честно» и «Обход».
   Каждую проверку отмечаю `/say TEST …`, результат ищу как «Проверка пройдена/неуспешна» в `build/client.log`.
   Скриншоты открываю сам через Read. В HANDOFF и коммите честно разделяю «проверено в игре» и «проверено только компиляцией».
4. Коммит на русском с подробным телом → `git push` → обновить `HANDOFF.md` (чек-лист) и `docs/BUGS.md` / `docs/PUZZLES.md`.
Звук в клиенте не включаю. Репозиторий не оформляю: README и CHANGELOG только текстом, как в прошлых релизах. Картинок, лицензии, GitHub-релизов и CI не трогаю.

### 0.4-1. Скользящий лёд (PUZZLES C.3)
- Блоки (`block/puzzle/ice/`):
  - `rune_glacier_block`: рунная глыба, неразрушима, `PushReaction.BLOCK`.
  - `ice_nest`: плита-гнездо, светится, когда занята.
  - `ice_bell`: ледяной колокол, сброс.
  - `glacier_hall`: невидимый контроллер зала с BE. Хранит стартовые позиции глыб и гнёзд и флаг SOLVED.
- Толчок. ПКМ по боковой грани отправляет глыбу от игрока. Своя сущность `SlidingGlacier` (по образцу `FallingBlockEntity`,
  без гравитации) плавно едет с частицами инея до препятствия и там снова становится блоком. Без телепорта.
- Решение: все гнёзда заняты → `PuzzleRewards.solved`, печати растворяются, Реликварий открыт. Колокол возвращает расклад из BE, поэтому софтлока нет.
- Защита:
  - пока зал не решён, в его объёме ничего нельзя поставить. Это обобщение `trial/TrialGuard` в `puzzle/PuzzleZoneGuard`: свой блок-стопор не сработает;
  - поршни не двигают глыбы;
  - толкать можно только в выживании и только стоя на полу зала;
  - глыба не уезжает за пределы зала.
- Уровни: 3 зала нарастающей сложности. Генератор строит расклады и **проверяет их BFS-решателем на Python**:
  каждый решаем, минимум ходов ≥ N, решение пишется в комментарий шаблона для сценария.
- Проверка: `puzzle_ice.txt`.
  - Честно: пройти решение решателя командами `use`. Ожидаю двери нет, в реликварии лут, в логе «Проверка пройдена».
  - Обход: сломать глыбу, поставить свой блок-стопор, поршень, толчок в креативе, колокол после решения. Все должны провалиться.
  - Скрины глыбы в движении и подсвеченного гнезда.

### 0.4-2. Зеркальный лабиринт (PUZZLES C.4)
- Свойство `SEALED` для `BeamMirrorBlock`, `BeamFilterBlock`, `BeamPrismBlock`. Дальше в тексте это «древние» блоки.

- Защита: та же зона без строительства (`PuzzleZoneGuard`). Свой фонарь не засчитывается: уже работает флаг `sealedSource`.
- Проверка: `puzzle_mirror.txt`.
  - Честно: повернуть зеркала Камертоном (`use`), получить три приёмника powered, затем реликварий.
  - Обход: свой фонарь, свои зеркала, сломать древнее зеркало, два приёмника из трёх.
