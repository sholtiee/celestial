# Головоломки без обходов: «Святилища» + новые загадки + аудит лазеек

## Context
Пользователь: больше головоломок; ни одну нельзя обойти — награда только за решение; то же для всех мелочей/недочётов мода.
Аудит существующих загадок нашёл реальные обходы:
1. **Печать-дверь** (`block/puzzle/SealedDoorBlock.java`) растворяется от ЛЮБОГО редстоун-сигнала → рычаг рядом = дверь открыта.
2. **Световые загадки**: `light_receiver`, `beam_lantern`, зеркала, призмы, фильтры — крафтятся и ломаются (strength 1.5–2). Можно принести свой фонарь+приёмник, выломать/переставить зеркала, или просто светить снаружи в окно.
3. **Испытания-загадки** (`TrialControllerBlockEntity.puzzleSolvedNearby`) засчитывают ЛЮБОЙ сигнал от блока с именем light_receiver/bell_altar/… → свой приёмник в арене = победа.
4. **Паркур-испытания**: эндер-жемчуг/элитры/пегас/столб из блоков до `trial_goal`.
5. **Сундуки с наградой** в постройках — обычные: прокопать стену, взрыв, воронка снизу.
6. **Рунный пьедестал**: неверный ответ без штрафа → перебор всего инвентаря.
7. Мелочи: комментарий в `BellAltarBlockEntity` не совпадает с кодом (5 нот всегда); колокол структуры ломается → мелодия неполная (софтлок); «горячая еда не греет».
Проверено и в порядке: `/celestial quest`, `/celestial beacon` проверяют дистанцию; печати/алтарь/плитки/кристаллы испытаний уже неразрушимы.

**Принцип**: запирать НАГРАДУ, а не геометрию; геометрию дополнительно защищать, пока святилище не решено. Креатив/опы — исключены из всех проверок.

## Этап A — каркас «Святилище» (anti-bypass)
- `puzzle/Sanctums.java` (новый):
  - структурный тег `data/celestial/tags/worldgen/structure/sanctums.json` (beam_temple, sky_ruins, observatory, trial_tower, citadel, sunken_temple, cloud_castle, flame_sanctuary, void_rift + новые).
  - `start(level,pos)` = `level.structureManager().getStructureWithPieceAt(pos, SANCTUMS)`; ключ святилища = `dim + start.getChunkPos()`.
  - `isSealed(level,pos)`: внутри куска святилища и ключа нет в `WorldState.flags` (`sanctum_open:<key>`).
  - `onPuzzleSolved(level,pos)`: скан bbox старта на блоки тега `celestial:puzzle_blocks` с `SOLVED=false`; если таких нет → флаг open, `dissolve` всех печать-дверей в bbox, открыть реликварии, титр «Святилище раскрыто».
- Защита, пока `isSealed` и игрок не креатив (`StoryEvents`-подобный init, напр. `puzzle/SanctumGuard.java`):
  - `PlayerBlockBreakEvents.BEFORE` → отмена + оверлей «Святыня противится…».
  - `UseBlockCallback`: BlockItem/ведро/огниво с целевой позицией в святилище → FAIL (кроме разрешённых предметов-ответов на блоках-загадках).
  - mixin `ServerExplosion` (фильтр взрываемых позиций в запечатанных святилищах).
  - mixin `PistonStructureResolver.resolve` → false, если двигаемый блок в запечатанном святилище.
  - `ThrownEnderpearl` → отмена телепорта в запечатанное святилище и во время паркур-испытания (mixin на `onHit`).
- `PuzzleRewards.solved` → вызывает `Sanctums.onPuzzleSolved` вместо локального скана дверей.
- `SealedDoorBlock`: убрать реакцию на редстоун (`neighborChanged`), только `dissolve` из Sanctums/испытаний.
- **Реликварий** `puzzle/ReliquaryBlock` + BE (новый): неразрушим, `PushReaction.IMMOVEABLE`, НЕ Container (воронки не тянут), хранит loot_table id; ПКМ: если святилище запечатано — «Заперто», иначе выдаёт лут (ролл на игрока, set UUID — каждому один раз). В gen-скриптах (`gen_structures.py`, `gen_abyss_boss.py`, `gen_places.py`) сундуки сокровищниц загадочных построек → реликварий.

## Этап B — починить существующие загадки
- Древние световые блоки (новые, неразрушимые, без лута, IMMOVEABLE, не крафтятся): `ancient_beam_lantern`, `ancient_mirror` (вращается Камертоном), `ancient_receiver` (защёлкивается `SOLVED` после 3 пульсов подряд). Регистрация в `ModBlocks`, модели/текстуры через `tools/gen_*.py` (свой арт), тег `puzzle_blocks`. Заменить в генераторах построек.
- `BeamTarget.onBeamHit` + `LightBeams.trace`: передавать позицию источника; `ancient_receiver` принимает луч только от `ancient_beam_lantern` того же святилища (`Sanctums.start` совпадает).
- `TrialControllerBlockEntity.puzzleSolvedNearby` → только блоки тега `puzzle_blocks` с `SOLVED=true` внутри того же святилища.
- Паркур: новые `trial_checkpoint` блоки; `reachGoal` засчитывается, только если все вехи арены пройдены по порядку; во время испытания: провал при полёте элитр, езде верхом, эффекте левитации; жемчуг отменяется (этап A).
- Рунный пьедестал: неверный ответ → блокировка этого пьедестала для игрока на 20 с, растущая ×2 (хранить в BE map UUID→until), звук/частицы «отвергнуто».
- Колокола: структурные колокола защищены святилищем; исправить комментарий/длину мелодии (4 + колокола/2, max 7) в `BellAltarBlockEntity`.
- Плитки-звёзды: уже неразрушимы; добавить ограничение — решение засчитывается, только если все плитки узора внутри одного святилища.

## Этап C — новые головоломки (каждая сразу с защитой этапа A)
1. **Звёздный кодовый замок** (Небо, обсерватория + башня этаж 4): 4 неразрушимых диска-созвездия (8 символов, ПКМ — повернуть), подсказки — фрески-плитки по постройке (генерируемые текстуры). Кнопка-печать «сверить»: неверно → блокировка 30 с ×2 + 1–2 Падших стража. Комбинация — сид от позиции святилища.
2. **Плиты памяти** (Небо, руины): плиты вспыхивают маршрутом (как колокола — проиграть); пройти шагами по порядку, `stepOn` только на земле, не верхом, не в элитрах; ошибка → плиты-облака исчезают (VanishingCloud), сброс.
3. ✅ СДЕЛАНО (2026-10-07, `block/puzzle/ice/`, `tools/gen_frozen_puzzles.py`, сценарий `puzzle_ice.txt`). **Скользящий лёд** (Ледяные Чертоги, цитадель — шаг 6 волны 0.4): рунные глыбы на льду, ПКМ сбоку толкает глыбу до препятствия; цель — все глыбы на плитах-гнёздах. Глыбы неразрушимы/IMMOVEABLE, позиции старта в BE зала → «ледяной колокол» сбрасывает расклад (нет софтлока).
4. ✅ СДЕЛАНО (2026-10-07, `BeamLockBlockEntity`, шаблон `mirror_maze/main`, сценарий `puzzle_mirror.txt`). **Зеркальный лабиринт** (Ледяные Чертоги): древние зеркала + фильтры, три цветных приёмника должны гореть одновременно (защёлка всех трёх в одном пульсе).
5. **Эхо во тьме** (Бездна, новое малое святилище на `cave_floor`): 4 камня-резонатора, ПКМ — звук эха с задержкой ∝ расстоянию до скрытого «ядра»; ударить в порядке от дальнего к ближнему. Свет гасит камни → нужна тьма (связка с механикой страха).
Каждая: блоки в теге `puzzle_blocks` со свойством `SOLVED`, решение → `PuzzleRewards.solved`, награда — реликварий; переводы ru/en через `gen_story.lang_patch`; запись в Кодекс (PLACES/Справочник).

## Проверка (autopilot, режим survival, `/effect clear @s` в начале)
Для каждой загадки сценарий `tools/scenarios/puzzle_<name>.txt` с двумя частями:
- **Честно**: решить → реликварий выдаёт лут, двери растворились, флаг `sanctum_open` в `/celestial status`.
- **Обход** (все должны ПРОВАЛИТЬСЯ, скрин + лог): сломать стену/реликварий; рычаг у двери; свой фонарь+приёмник; TNT у стены; поршень в стену; воронка под реликварием; жемчуг в запечатанный зал и к финишу паркура; перебор ответов пьедесталу; повторный клик реликвария.
После каждого этапа: `./tools/build_assets.sh` → `./gradlew build` → сценарии → коммит (рус.) → push → HANDOFF.md (раздел «Головоломки и защита»).

## Лимит
5-часовой лимит сейчас 84% — по правилу пользователя остановка на 90%. Этапы идут по порядку A→B→C→D, каждый коммитится отдельно; если лимит подходит — стоп после ближайшего коммита, остаток в HANDOFF.
